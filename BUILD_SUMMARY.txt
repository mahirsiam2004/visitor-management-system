DATABASE SCHEMA
================================================================================

Profiles Table:
  • id (UUID, PK)
  • email (VARCHAR, UNIQUE)
  • full_name
  • phone_number
  • apartment_number
  • role (ENUM: resident, security, admin)
  • created_at, updated_at

Guest Passes Table:
  • id (UUID, PK)
  • guest_id (VARCHAR, UNIQUE)
  • guest_name
  • guest_phone
  • resident_id (FK → profiles)
  • apartment_number
  • visit_date, visit_time
  • expiry_time
  • duration_hours
  • purpose
  • qr_token (UNIQUE)
  • status (ENUM: valid, expired, revoked)
  • created_at, updated_at

Entry Logs Table:
  • id (UUID, PK)
  • guest_pass_id (FK → guest_passes)
  • security_guard_id (FK → profiles)
  • entry_time
  • exit_time
  • status (ENUM: inside, completed)
  • created_at, updated_at

Indexes:
  • idx_guest_passes_resident_id
  • idx_guest_passes_qr_token
  • idx_guest_passes_status
  • idx_entry_logs_guest_pass_id
  • idx_entry_logs_security_guard_id
  • idx_profiles_role

GETTING STARTED
================================================================================

1. Set Environment Variables:
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
   NEXT_PUBLIC_DEV_SUPABASE_REDIRECT_URL=http://localhost:3000/auth/callback

2. Install Dependencies:
   pnpm install

3. Run Development Server:
   pnpm dev

4. Open Browser:
   http://localhost:3000

5. Start Testing:
   - Sign up as a resident
   - Create a guest pass
   - Scan QR code (or enter guest ID)
   - Check-in/check-out
